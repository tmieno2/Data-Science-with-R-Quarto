library(dplyr)

corn_data %>%
  filter(state == "NE") %>%
  group_by(county) %>%
  summarize(mean_yield = mean(yield))
# A tibble: 3 × 2
  county   mean_yield
  <chr>         <dbl>
1 Buffalo        182.
2 Custer         171.
3 Dawson         189.
The pipe %>% passes the result on the left into the function on the right as its first argument.
Transcript 3 ¶

So the pipe is the thing to get comfortable with today. Read %>% as "and then". We take the corn data, and then we keep only Nebraska, and then we split it by county, and then we take a mean.

Notice I never assigned anything to an intermediate variable. That is the whole point — you can read the chain top to bottom as a sentence, in the order the work actually happens.

If you have used base R you might be reaching for nested function calls. Resist that for now; we come back to when nesting is the clearer choice in Chapter 5.
