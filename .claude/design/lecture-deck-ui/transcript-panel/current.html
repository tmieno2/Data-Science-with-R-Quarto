Summarizing by group

SyntaxExampleYour turn

Chain the verbs together with the pipe:

library(dplyr)

corn_data %>%
  filter(state == "NE") %>%
  group_by(county) %>%
  summarize(mean_yield = mean(yield))
# A tibble: 3 × 2
  county   mean_yield
1 Buffalo        182.
2 Custer         171.
3 Dawson         189.

So the pipe is the thing to get comfortable with today. Read %>% as "and then". We take the corn data, and then we keep only Nebraska, and then we split it by county, and then we take a mean.

Notice I never assigned anything to an intermediate variable. That is the whole point — you can read the chain top to bottom as a sentence.

If you have used base R you might be reaching for nested function calls. Resist that for now.
