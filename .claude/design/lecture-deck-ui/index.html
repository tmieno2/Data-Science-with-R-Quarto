Lecture Deck UI

Design options for the AECN 896-05 revealjs decks. Every mockup renders at the real logical slide size, 1050 × 700. Start with current in each group to see what ships today, then the options. Three directions run across all four groups — Chalkline, Ledger, Notebook — so picking one gives a coherent system rather than four separate decisions. Notebook is adopted — those four files carry the -ADOPTED suffix.
