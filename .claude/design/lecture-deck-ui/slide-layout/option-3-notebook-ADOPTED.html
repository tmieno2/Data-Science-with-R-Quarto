Summarizing by group

Ch 3 · Data Wrangling
SyntaxExampleYour turn 
library(dplyr)

corn_data %>%
  filter(state == "NE") %>%
  group_by(county) %>%
  summarize(mean_yield = mean(yield))
# A tibble: 3 × 2
  county   mean_yield
  <chr>         <dbl>
1 Buffalo        182.
2 Custer         171.
3 Dawson         189.
The pipe %>% passes the result on the left into the function on the right as its first argument. Read it as "and then".
Watch for summarize() drops every column you did not group by or compute. That is intended.
