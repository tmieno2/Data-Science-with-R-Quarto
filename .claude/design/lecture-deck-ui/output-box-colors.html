R output box — four alternatives

Currently #efece3, a warm grey that sits only 2% away from the code block's #f4f1e9 — close enough that on a projector the two blocks can merge into one grey slab. Each option below is shown under the real code block, since the pairing is the whole question.

A · Cool grey

#eceef0

corn_data %>% group_by(county) %>%
  summarize(mean_yield = mean(yield))
# A tibble: 3 × 2
  county   mean_yield
1 Buffalo        182.
2 Custer         171.

Separates by temperature, not lightness: code stays warm (paper family, "what you wrote"), output goes cool ("what the machine said"). Reads clearly even on a washed-out projector. The most legible of the four.

B · Deeper warm

#e9e3d5

corn_data %>% group_by(county) %>%
  summarize(mean_yield = mean(yield))
# A tibble: 3 × 2
  county   mean_yield
1 Buffalo        182.
2 Custer         171.

Same hue family, just further down. Keeps the page entirely warm and quiet. Weakest separation of the four — it is a lightness step only, so it is the first to collapse on a bad projector.

C · Blue tint

Ties output to the ink-blue accent, so the deck has one cool colour with one meaning. Strongest separation. Risk: blue is also the active tab edge and the try-it rule, so it is doing a third job here.

D · No box — paper with a rule

Output stops being a box and becomes an indented continuation of the code. Quietest, and the only one that adds no new fill to a slide — which matters on slides already at the 700px ceiling. Weakest if a student is scanning for "where is the answer".
