Notebook tabs — index cards

The active card is paper-coloured against tinted inactive cards, lifted by a 3px accent edge along its top. Every label is ink on a warm ground — 14.9:1 active, 6.6:1 inactive — so no state depends on white text over a mid-tone fill, which is exactly how the current row fails.
